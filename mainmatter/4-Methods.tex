\section{Methods: characterising spectra using \texttt{asap}}
\label{sec:methods}

This chapter describes how we recover atmospheric and magnetic parameters from the template spectra of Sect.~\ref{sec:obs_preparation}. We use \texttt{asap}, a retrieval pipeline that couples a forward model, which turns a parameter set into a synthetic spectrum, with an MCMC sampler, which explores the parameter space and scores each proposal by how well its spectrum reproduces the observations. Run as a loop, the two map out the posterior distribution of the parameters, from which we report point estimates (posterior medians) and credible intervals. The parameters are the effective temperature $T_\mathrm{eff}$, surface gravity $\log g$, metallicity $\mathrm{[M/H]}$, radial velocity $v_r$, macroturbulence $\zeta_\mathrm{RT}$, and a set of magnetic filling factors $f_i$ defined on a grid of field strengths $B_i$ spanning $0$--$10\,\mathrm{kG}$.

The chapter follows the pipeline from a single fit to the full sample. Sect.~\ref{sec:methods_fit} sets out the \texttt{asap} retrieval itself: the forward model, how magnetic activity enters it, the free parameters and priors, and the likelihood. Sect.~\ref{sec:methods_linelist} describes the common atomic and molecular line list, which selects the spectral regions that enter the likelihood. Sect.~\ref{sec:methods_filter} adds a per-star, $\chi^2$-based filter that prunes regions the forward model fits poorly, so a single starting list can serve a diverse sample. Sect.~\ref{sec:methods_bic} introduces a post-hoc BIC scan that fixes the number of magnetic components per star, in place of the fixed magnetic grids used by \citet{cristofari+2022b, cristofari_2023b, reiners+2022}.

Sect.~\ref{sec:methods_linelist} describes the atomic and molecular line list common to all stars, drawn from the VALD3 database [CITATION NEEDED: vald3]. Sect.~\ref{sec:methods_filter} introduces a per-star, $\chi^2$-based filter that prunes spectral regions in which the forward model fits the data poorly, allowing the use of a uniform initial list across a heterogeneous sample. Sect.~\ref{sec:methods_bic} introduces a post-hoc $\mathrm{BIC}$ scan that selects the number of magnetic filling-factor components per star, in contrast to the fixed magnetic grids used by \citet{cristofari+2022b, cristofari_2023b, reiners_2022}. Sect.~\ref{sec:methods_campaign} closes by describing how these elements are assembled into a three-phase campaign that produces the self-consistent parameter set used in the chapters that follow.

\subsection{The \texttt{asap} retrieval}
\label{sec:methods_fit}
The forward model and the sampler run together in a loop. At each step the sampler proposes a parameter set, the forward model renders the corresponding synthetic spectrum, and the likelihood measures its agreement with the observation, so the proposal is accepted or rejected accordingly. Over many steps the accepted positions trace out the posterior. We use the affine-invariant ensemble sampler \texttt{emcee}\footnote{\url{https://emcee.readthedocs.io/en/stable/}} \citep{emcee}.

The remainder of this section follows that division. Sect.~\ref{sec:methods_forward} and Sect.~\ref{sec:methods_magnetic} describe the forward model and how magnetic activity enters it. Sect.~\ref{sec:methods_freeparams} lists the sampled parameters and their priors and Sect.~\ref{sec:methods_likelihood} the likelihood and error treatment.

\subsubsection{Forward model}
\label{sec:methods_forward}
Synthetic spectra are pulled from the precomputed \texttt{ZeeTurbo} grid and linearly interpolated over the 3D box $(T_\mathrm{eff}, \log g, \mathrm{[M/H]})$ at each magnetic component $B_i$ spanning $0$--$10\,\mathrm{kG}$ in $1\,\mathrm{kG}$ steps. This produces 11 spectra $S_i(\lambda)$, one per field strength, which the magnetic model of Sect.~\ref{sec:methods_magnetic} combines into the single spectrum $S_\mathrm{mag}= \sum f_i S_i$ used in the rest of the forward model. Figure~\ref{fig:forward_model} traces this construction for a single Zeeman-sensitive Ti\,\textsc{i} line in Gl~388 (AD~Leo). The Zeeman broadening grows visibly with $B_i$ across these spectra.

The combined spectrum is then shifted in wavelength to the stellar rest frame. The relativistic Doppler factor
\begin{equation}
    \label{eq:doppler}
    \mathcal{D}(v_r) \;=\; \sqrt{\frac{1 + \beta}{1 - \beta}} , \qquad \beta \equiv \frac{v_r}{c}
\end{equation}
is evaluated, and the synthetic wavelength solution is multiplied by it. An initial value for $v_r$ is obtained once, before sampling, by cross-correlating the observed spectrum against a VALD absorption-line mask. Then the synthetic spectrum is convolved with a Gaussian profile of full width at half maximum (FWHM) of 4.3 and 4.4 km s$^{-1}$ to account for the instrumental width of SPIRou and NARVAL/ESPaDOnS, respectively. Macroturbulence is a free parameter, applied in radial-tangential mode ($\zeta_\mathrm{RT}$). Rotational broadening is supported by the forward model but, for the slow-rotating M dwarfs of this sample, $v\sin i$ is deliberately fixed to zero, because at the instrumental resolution rotation is unresolved, and the fitted $\zeta_\mathrm{RT}$ acts as an effective broadening parameter that absorbs the combined macroturbulent and residual rotational broadening. The fully transformed synthetic spectrum is then resampled onto a reference wavelength grid.

\subsubsection{Modelling magnetic intensity}
\label{sec:methods_magnetic}
Following \citet{shulyak+2010, shulyak+2014, kochukhov+2020, reiners+2022, cristofari_2023a}, the stellar spectrum is modelled as a linear combination of the spectra computed with \texttt{ZeeTurbo} for various magnetic field strengths. These interpolated spectra are linearly combined in flux, weighted by the filling factors $f_i$,
\begin{equation}
  \label{eq:magnetic-mixing}
  S_\mathrm{mag}(\lambda) = \sum_{i=0}^{N_B} f_i \, S_i(\lambda),
  \qquad \sum_{i=0}^{N_B} f_i = 1,
  \qquad f_i \geq 0 ,
\end{equation} 
where each weight $f_i$ is the fraction of the disc-integrated flux emitted by regions at field strength $B_i$. The two constraints have direct meaning: $f_i \geq 0$ because a region cannot cover a negative fraction of the disc, and $\sum_i f_i = 1$ because the strengths must account for the whole visible surface, with $f_0$ the non-magnetic fraction. Together they make $\{f_i\}$ a normalised distribution over field strength, which can be seen as a histogram, binned at the grid resolution, of how the visible disc is partitioned among the available strengths.

The MCMC does not sample all $N_B + 1$ weights independently. It samples the $N_B$ magnetic factors $f_1, \dots, f_{N_B}$ and fixes the non-magnetic factor by closure, $f_0 = 1 - \sum_{i \geq 1} f_i$.

\subsubsection{Free parameters and priors}
\label{sec:methods_freeparams}
The MCMC samples a common parameter set for every star in the sample: the atmospheric parameters $T_\mathrm{eff}$, $\log g$ and $[\mathrm{M/H}]$, the radial velocity $v_r$, the macroturbulent velocity $\zeta_\mathrm{RT}$, and the magnetic filling factors $f_1,\dots,f_{N_B}$. All priors are uniform. Their bounds are listed in Table~\ref{tab:mcmc_priors}. The bounds on the atmospheric parameters are inherited from the \texttt{ZeeTurbo} grid extents. The prior on $\{f_1,\dots,f_{N_B}\}$ is uniform over the simplex defined in Sect.~\ref{sec:methods_magnetic}. $N_B$ is not itself a free parameter, but is fixed for a given run and selected post-hoc by the BIC scan (Sect.~\ref{sec:methods_bic}). The remaining parameters supported by \texttt{asap}, $v\sin i$ (Sect.~\ref{sec:methods_forward}), $[\alpha/\mathrm{Fe}]$, the veiling factor, and any additional Gaussian broadening, are held fixed and set to zero across the sample.

\subsubsection{Likelihood and error estimation}
\label{sec:methods_likelihood}
Following \citet{cristofari_2023a, cristofari_2023b}, we adopt a pixel-wise Gaussian likelihood. With $O_i$ the observed normalised flux at pixel $i$, $M_i$ the synthetic flux returned by the forward model, and $\sigma_i$ the observational uncertainty on $O_i$, the chi-squared statistic is
\begin{equation}
    \label{eq:chi2}
    \chi^2 = \sum_{i=1}^{n} \frac{(O_i - M_i)^2}{\sigma_i^2} ,
\end{equation}
and the log-likelihood is
\begin{equation}
    \label{eq:likelihood}
    \ln \mathcal{L} = -\frac{1}{2}\chi^2 - \frac{1}{2}\sum_{i=1}^{n} \ln\!\left(2\pi\sigma_i^2\right) ,
\end{equation}
where $n$ is the number of fitted pixels.

To absorb modelling-induced systematics that the pipeline uncertainties do not capture, we follow the two-pass procedure of \citet{cristofari_2023a, cristofari_2023b}. A first MCMC is run with the original $\sigma_i$. The residuals at the posterior median yield a reduced chi-squared $\chi^2_\nu = \chi^2/\nu$, with $\nu = n - k$ degrees of freedom for $k$ free parameters. In the subsequent run, all pixel errors are inflated as $\sigma_i \to \sigma_i\sqrt{\chi^2_\nu}$, so that the best fit has $\chi^2_\nu \approx 1$.

The 16th--84th percentiles of the second-pass posterior, taken relative to the median, define what we call the \emph{formal} error bars. These formal bars are statistical lower bounds that reflect only the width of the posterior and do not capture systematics or model error, which is why the empirical floors of \citet{cristofari_2023b, cristofari_2023a} are adopted as the reported uncertainties. Typical formal values are $5$--$20$~K in $T_\mathrm{eff}$ and $0.005$--$0.080$~dex in $\log g$ and $[\mathrm{M/H}]$. \citet{cristofari_2023b, cristofari_2023a} found these formal errors to be significantly smaller than the dispersion of derived parameters across reasonable modelling assumptions, and proposed \emph{empirical} error bars obtained by adding in quadrature a floor of $30$~K in $T_\mathrm{eff}$, $0.05$~dex in $\log g$, and $0.10$~dex in $[\mathrm{M/H}]$.

\subsection{Line list}
\label{sec:methods_linelist}

A careful selection of absorption lines is crucial. Not all of the observed spectrum is usable, and not all of it is equally informative. Parts are degraded by low signal-to-noise or contaminated by
telluric features, and the forward model reproduces some regions more
faithfully than others. We therefore restrict the analysis to a curated set of spectral regions, since the likelihood of Sect.~\ref{sec:methods_likelihood} is evaluated only over them: these regions alone determine which features drive the joint posterior over $T_\mathrm{eff}$, $\log g$, $\mathrm{[M/H]}$, $v_r$, $\zeta_\mathrm{RT}$, and the filling factors $f_i$. In what follows we use \emph{line list} for the set of spectral lines of interest and \emph{regions}
for the wavelength windows around them on which the likelihood is computed.

Each parameter alters a line's strength, width, or central wavelength in ways that partly mimic the others, so the list must be built to separate these responses rather than let them be absorbed into one another \citep{Kochukhov_2021}. The degeneracy between metallicity and magnetic intensification is a clear example: both raise the equivalent width of magnetically sensitive Fe lines. A transition's magnetic sensitivity is set by its effective Land\'e factor $g_\mathrm{eff}$, which fixes the size of the Zeeman splitting at a given field strength, so a list dominated by high-$g_\mathrm{eff}$ Fe transitions cannot distinguish a more metal-rich, weakly magnetic star from a less metal-rich, strongly magnetic one.

These degeneracies set the selection criteria. The list should span a range of $g_\mathrm{eff}$, since comparing transitions of differing magnetic sensitivity is what separates Zeeman broadening from the rotational and turbulent broadening. Longer-wavelength lines are favoured, as the Zeeman splitting grows with wavelength \citep{donati_landstreet+2009, Reiners+2012}. The group of Ti~\textsc{i} lines near 970~nm identified by \citet{Kochukhov+2017, Shulyak+2017, Kochukhov_2021} is especially valuable for this reason. It is equally important to include at least one transition with negligible $g_\mathrm{eff}$, because such a line pins down the non-magnetic broadening, principally the macroturbulence $\zeta_\mathrm{RT}$ and the stellar rotation, independently of the field, disentangling the two broadening effects.

To assemble and refine this list we built \texttt{wave\_explorer}, an
interactive spectrum-exploration tool. For a given star it overlays the observed spectrum on a synthetic spectrum generated from the point estimates of the parameters of a completed pipeline run, showing directly which features the forward model reproduces and which it misses. Region boundaries can be adjusted, new windows added, and existing ones removed. The tool also reports the residuals between observation and model and assigns a quality flag from the mean pixel-wise $\chi^2$. A high value marks a systematic mismatch, such as a poorly modelled line, an unmasked telluric, or a continuum error. Sorting by this flag produces a worst-first table, letting us quickly inspect where model and data disagree most and prune or remask accordingly. On top of this, lines from the VALD database are overplotted and labelled by species, indicating which transitions are responsible for each observed feature. A screenshot of the tool is displayed in Fig.~\ref{fig:wave_explorer}.

\texttt{wave\_explorer} can be run on a single star or on many at once.
Single-star mode tailors a list to one target, whereas multi-star mode builds a list that performs well across a diverse sample, as required when a common selection must serve many stars. In multi-star mode the displayed spectrum and residuals are the pixel-by-pixel averages of the observed and model flux on a common wavelength grid, which exposes the features shared across the sample. The quality flag of each region is then the median $\chi^2$ over stars, so a region is penalised only when it fits poorly for the sample as a whole rather than for a single outlier.

The initial optical list used for the NARVAL/ESPaDOnS configuration of the retrieval comprises $29$ wavelength regions in the range $747$--$979\,\mathrm{nm}$. The species and effective Land\'e factor $g_\mathrm{eff}$ of each region are identified with the strongest VALD line falling inside the region. Table~\ref{tab:linelist_opt} reports the resulting identifications. The list is split roughly evenly between Ti\,\textsc{i} ($14$ lines) and Fe\,\textsc{i} ($13$ lines), with single Mg\,\textsc{i} and V\,\textsc{i} regions.

\subsection{Per-star line-list filter}
\label{sec:methods_filter}

The common list of Sect.~\ref{sec:methods_linelist} is a single compromise for a diverse sample. Because the targets of Table~\ref{tab:obs_summary} span a range of M spectral types and data quality, a region that is clean and well modelled in one star can be unusable in another. Telluric absorption falls at different stellar-frame wavelengths depending on a star's radial velocity and observing epochs, so a line free of contamination in one target may be blended in another, and low S/N can leave a region uninformative. Line strengths also depend strongly on $T_\mathrm{eff}$, so a transition that is clean in a warmer M dwarf can be overwhelmed by a growing blend in a cooler one. \citet{reiners+2022} address both by tailoring the selection per star: a minimum S/N per line, a rejection of lines lying too close to tellurics, and a progressive exclusion of lines below $T_\mathrm{eff}=3750$ and $3600\,\mathrm{K}$. Rather than impose fixed temperature cuts, we identify the regions to drop empirically, from a short diagnostic run of each star.

The production phase (green) is in either case an ordinary pipeline run that differs only in the line list it uses, and it is this run that yields the posterior estimates.}
\label{fig:linelist_filter}
\end{figure}

The filter runs in two phases (Fig.~\ref{fig:linelist_filter}). In the diagnostic phase the star is fitted on the full common list with a reduced number of MCMC steps, the aim being a representative synthetic spectrum rather than a converged posterior. The forward model evaluated at the point estimates of this posterior gives this synthetic spectrum, which we compare to the observations region by region. For a region $R$ we take the mean per-pixel $\chi^2$ over its $N_R$ fitted pixels ($\chi^2_R/N_R$). This is also the quantity reported by the tool used to build the list by hand (Sect.~\ref{sec:methods_linelist}), so manual and automatic selection rank regions using a common method. Because the diagnostic synthetic spectrum depends on the model configuration of the diagnostic fit, the filtered list inherits that dependence, so runs that adopt different magnetic configurations can retain slightly different sets of regions.

A region is rejected when $\chi^2_R/N_R > 50$, a threshold set by inspecting the per-region model. Below the threshold the model reproduces the data well, while higher values mark mismatches such as an unmodelled blend, a residual telluric, or a continuum error. Since the metric is a mean of squared, error-normalised residuals, $50$ corresponds to a mean per-pixel residual of $\sim\!7\sigma$, so the cut is deliberately permissive, leaving marginal regions in the fit, where the error-inflation step of Sect.~\ref{sec:methods_likelihood} already down-weights them.

Figure~\ref{fig:region_filtering} shows the filter at work for Gl~445, putting the diagnostic phase of Fig.~\ref{fig:linelist_filter} into practice. Each panel sets the observed spectrum against the model fitted to it over one region of the common list, with the grey band marking the pixels that enter $\chi^2_R/N_R$ and the value itself printed in the corner, in green where the region is kept and red where it is dropped. The kept regions in the left column track the model closely and sit below the threshold. The rejected regions in the right column fall in the $967$--$979\,\mathrm{nm}$ band, where telluric absorption that the model does not reproduce pulls it away from the data and sends $\chi^2_R/N_R$ over the threshold.

The diagnostic check sets the production run. If no region is rejected, the common list is final and the run continues to the full production length. If any region is rejected, the fitted pixels and the likelihood have changed, and the star is refitted from scratch on its filtered list. The filtered list is saved as a copy of the common list with rejected regions commented out and annotated with their $\chi^2_R/N_R$, preserving each star's provenance. In either case the production run is an ordinary pipeline run (Sect.~\ref{sec:methods_fit}) differing only in its line list, and it is this run that yields the reported parameters.


\subsection{Magnetic-component selection via BIC}
\label{sec:methods_bic}
The magnetic model is described in Sect.~\ref{sec:methods_magnetic}. Its filling factors are constrained to be non-negative ($f_i \geq 0$). For weakly magnetic stars this introduces an asymmetry: the filling factors of the strong-field components cannot scatter below zero, so noise pushes their posterior means to small positive values rather than averaging out around zero. Because the mean field $\langle B \rangle = \sum_i B_i f_i$ weights each component by its field strength, these spurious filling factors are amplified by the large $B_i$ of the strong-field components, biasing $\langle B \rangle$ upward. The full magnetic grid therefore overestimates $\langle B \rangle$ for weakly magnetic stars, and we reduce the number of components carried as free parameters to recover a lower, less biased estimate.

We select the number of magnetic components per star with the Bayesian information criterion \citep{Schwarz+1978, Sharma_2017},
\begin{equation}
    \label{eq:bic}
    \mathrm{BIC} = -2 \ln \mathcal{L} + k\,\ln n,
\end{equation}
where $\mathcal{L}$ is the likelihood (Eq.~\ref{eq:likelihood}) evaluated at the maximum-likelihood parameters of the production run, $k$ is the number of free parameters, and $n$ is the number of fitted spectral pixels. The first term rewards goodness of fit, while the penalty $k\ln n$ grows with model complexity, so an additional component is justified only when it improves the likelihood enough to outweigh the penalty. The configuration with the lowest BIC is preferred.

We apply this post hoc, without re-running the MCMC. The production run (Sect.~\ref{sec:methods_filter}) uses a magnetic grid spanning $0$--$10\,\mathrm{kG}$ in $1\,\mathrm{kG}$ steps. From its best-fit solution we compute the BIC of the full configuration and then collapse the grid from the top down. At each step the strongest component is removed and its filling factor transferred to the next-strongest component, the synthetic spectrum is recomputed with all other parameters held at their best-fit values, and the likelihood and BIC are re-evaluated, lowering $k$ by one. Transferring the filling factor to the adjacent bin rather than discarding it lowers $\langle B \rangle$ by only $f_{\rm drop}\,\Delta B$ per step (with $\Delta B = 1\,\mathrm{kG}$ the grid spacing), so the collapse traces a smooth, monotonically decreasing sequence in $\langle B \rangle$. We repeat until only the non-magnetic component remains and adopt the lowest-BIC configuration. The chosen configuration is then rerun in the production phase with the star's filtered line list from the diagnostic phase, from which the reported $\langle B \rangle$ is derived. Figure~\ref{fig:bic_scan_ds_leo} illustrates this scan for Gl~410, where the BIC turns over once the unsupported high-field components have been stripped. Because removing a genuine strong-field component sharply degrades the fit while removing a spurious one barely changes it, the criterion is self-regulating.
